## Root causes (rtl/core/sigil_core.sv at 84974af)

1. viota.m: the vector legality check (vec_align_bad) gave VOP_IOTA the
   default group sizes, ex_vs2_log2 = LMUL, so vs2 had to be aligned to
   LMUL. vs2 of viota.m is a mask register (EEW=1, a single register),
   like vmsbf.m's (VOP_MSBIT, already a single register). Legal programs
   using a mask register that is not a multiple of LMUL trapped. Spec:
   RVV 1.0 sec. 15.8 (viota.m vd, vs2, vm: vs2 is a mask register).
2. .vf scalar operands: the vector unit received f[rs1] unmodified. The
   FPU-computed .vf forms (vfadd.vf, vmfle.vf, ...) treat a non-NaN-boxed
   single as the canonical NaN inside the FPU, but vfmv.v.f, vfmv.s.f,
   vfmerge.vfm and vfslide1up/down.vf write the scalar directly and took
   its low 32 bits. Spec: RVV 1.0 sec. 13 (vector-scalar FP forms: when
   FLEN > SEW, an f register value that is not validly NaN-boxed is
   replaced by the canonical NaN; Spike gives 0x7fc00000).

Fix (63a50a5): VOP_IOTA checks vs2 as a single register; the core
presents the canonical NaN (0xffffffff_7fc00000) as the .vf scalar when
SEW=32 and f[rs1][63:32] != 0xffffffff, for every .vf form.
