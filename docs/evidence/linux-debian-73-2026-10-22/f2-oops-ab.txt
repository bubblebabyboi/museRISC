Measured on the way (run 1, full map, sigil-f2.dtb): host load of the 8 GiB

Conclusion (11:35): the trigger is the Debian/systemd workload itself
(dynamically linked code spread over many pages), not memory size, PA range,
HBM, ISA extensions, BPF, jump labels, ASIDs or THP. Small-footprint stress
(memstress, busybox execstress, pmemstress) did not reproduce it in minutes.
The RTL hunt (branches 73-oops-mmu / 73-oops-sim-repro,
sw/core-tests/ptw_preempt_directed.S) found an MMU walker race that fits: a
data-TLB miss preempts an in-flight instruction-fetch page walk and the data
walk consumes the fetch walk's outstanding PTE response as its own first PTE
(wrong root) -> wrong translation; it needs a load near the end of a code
page while the next code page misses in the ITLB, and DDR4-like latency
(~45 cycles on F2). F2 instance terminated 11:35 UTC; the Debian boot is
re-run on the AFI with the fix.

Platform side notes (for a platform issue, not fixed here):
- UART garbling after interrupted runs. Sequence: run 1 (sigil_host --console
  under pexpect) was stopped with SIGINT (sudo pkill -INT sigil_host); runs
  2-5 were started with --no-markers --timeout N (no --console, stdin
  /dev/null) and each previous sigil_host was SIGINT'd before the next
  started. From run 3 on, the console output lost many bytes ("[ 0.798996]
  IPortr_h hatable en, 14 bs" for "IP idents hash table entries"), also in
  the following --console runs (memstress, run "memstress2"), already in the
  OpenSBI banner. After fpga-clear-local-image + fpga-load-local-image (and
  the automatic DDR4 scrub) the console was byte-exact again (runs 6-11).
- Self restarts: within single sigil_host runs (exp-nohbm.host line 386,
  exp-ddr2g.host line 189, exp-minisa.host line 122) the OpenSBI banner
  appears again right after an oops trace ends ("---[ end trace ... ]---"),
  i.e. the SoC restarted OpenSBI without a host reload (--on-reboot exit was
  given; sigil_host printed no "finisher" message). exp-nohbm.host also
  starts with "discarded 1024 UART bytes from a previous run": the SIGINT'd
  previous sigil_host had left the SoC running (drop mode).
